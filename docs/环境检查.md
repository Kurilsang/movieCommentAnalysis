## ⚠️ JDK 发行版硬要求

ONNX Runtime Java 1.21.0+ 在 Windows 上用 VC 14.42 编译，**与部分 JDK 发行版冲突，会抛 `UnsatisfiedLinkError`**。DJL 官方测试过的发行版：

- ✅ **Eclipse Temurin 17**（当前使用）
- ✅ **Azul Zulu 17**
- ❌ 不要用：Oracle JDK、GraalVM、Corretto、Liberica（未测试）

另需 **MSVC++ Redistributable**（ONNX Runtime 的隐性依赖，见 microsoft/onnxruntime#24310）。

## MySQL（免安装版）

公司电脑无虚拟化权限 → 不能用 Docker。用 ZIP 免安装版，**不需要管理员权限**。

```powershell
# 首次初始化（已执行过，无需重复）
cd <mysql目录>\bin
.\mysqld --initialize-insecure --console

# 启动（前台，另开一个终端保持运行）
.\mysqld --console

# 设置 root 密码 + 建库（已执行过）
.\mysql -u root -e "ALTER USER 'root'@'localhost' IDENTIFIED BY 'root'; CREATE DATABASE IF NOT EXISTS movie_sentiment DEFAULT CHARACTER SET utf8mb4;"
```

配置见 `my.ini`。数据库：`movie_sentiment`，账号 `root` / `root`。

> **MySQL 26.x 变更**：`default-authentication-plugin` 配置项已被移除，写进 `my.ini` 会导致启动失败。


## 数据导入（自动，幂等）

后端启动时自动执行，无需手工操作：

1. `CsvDataImporter`（`@Order(1)`）从 `data/*.csv` 导入电影与评论
2. `PrecomputeRunner`（`@Order(2)`）预计算全库分析结果
3. `AdminSeeder`（`@Order(3)`）确保存在管理员账号

> **⚠️ 顺序不可调换**：`PrecomputeRunner` 若早于 `CsvDataImporter` 执行，会看到 0 条评论而跳过，导致雷达图全为 0。`StartupOrderTest` 是这条约束的回归测试。

重复启动不会产生重复数据。想强制重新导入：清空 `comment` / `movie` 表后重启。
