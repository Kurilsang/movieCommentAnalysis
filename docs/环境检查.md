| **Docker Desktop** | MySQL + Redis 无法启动 | 4.x（或改用本地 MySQL 8 + Redis 7） |
| Python 3.x | ONNX 导出（`ml/` 阶段） | 3.10–3.12，加 `transformers`/`optimum`/`onnxruntime` |

## 建议安装顺序

1. **JDK 17**：https://adoptium.net/temurin/releases/?version=17（选 Windows x64 `.msi`，勾选 "Add to PATH" 和 "Set JAVA_HOME"）
2. **Maven**：https://maven.apache.org/download.cgi（解压到 `D:\tools\maven`，把 `D:\tools\maven\bin` 加入 PATH）
3. **Docker Desktop**：https://www.docker.com/products/docker-desktop/（Windows 需启用 WSL2 或 Hyper-V）

装完后重跑：

```bash
# 验证
java -version    # 期望 17.x
mvn -v           # 期望 3.9.x
docker compose version

# 启动
docker compose up -d
cd backend && mvn spring-boot:run
```
