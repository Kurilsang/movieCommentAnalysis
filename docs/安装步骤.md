# 环境安装步骤（Windows）

## ⚠️ 必读：JDK 发行版要求

ONNX Runtime Java 1.21.0+ 在 Windows 上用 **VC 14.42** 编译，**与部分 JDK 发行版冲突，会抛 `UnsatisfiedLinkError`**。DJL 官方文档明确测试过的发行版：

- ✅ **Eclipse Temurin 17**（Adoptium）
- ✅ **Azul Zulu 17**

❌ 不要用：Oracle JDK、OpenJDK 部分发行版、GraalVM、Corretto、Liberica（未测试）

**安装后 ONNX Runtime 还需要 MSVC++ Redistributable**（此依赖未文档化，见 microsoft/onnxruntime#24310）。

---

## 1. JDK 17（Temurin）

下载：https://adoptium.net/temurin/releases/?version=17

- 选 **Windows x64** → `.msi` 安装包
- 安装时勾选：
  - ✅ **Add to PATH**
  - ✅ **Set JAVA_HOME variable**
- 验证：

```powershell
java -version
# 期望：openjdk version "17.0.x" ...
echo $env:JAVA_HOME
# 期望：C:\Program Files\Eclipse Adoptium\jdk-17.0.x.x-hotspot\
```

## 2. Maven 3.9.x

下载：https://maven.apache.org/download.cgi → `apache-maven-3.9.9-bin.zip`

- 解压到 `D:\tools\maven`（或任意路径）
- 把 `<maven路径>\bin` 加入系统 PATH
- 验证：

```powershell
mvn -v
# 期望：Apache Maven 3.9.x
```

## 3. MSVC++ Redistributable（ONNX Runtime 依赖）

下载：https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

- 选 **x64** 的 `vc_redist.x64.exe`，安装
- 这是 ONNX Runtime 的隐性依赖，不装会在 Java 加载原生库时报错

## 4. Docker Desktop

下载：https://www.docker.com/products/docker-desktop/

- Windows 需启用 **WSL2** 或 **Hyper-V**
- 安装后验证：

```powershell
docker -v
docker compose version
```

## 5. Python 3.10–3.12（仅 `ml/` 导出阶段需要）

下载：https://www.python.org/downloads/ → 3.12.x Windows installer

- 安装时勾选 ✅ **Add python.exe to PATH**
- 验证：

```powershell
python --version
pip install transformers==4.* optimum onnxruntime
```

⚠️ `transformers` 5.x 可能破坏 `optimum` 导出。若导出报错，固定 `transformers` 到 4.x。

## 装完后重跑验证

```powershell
cd "D:\Program Files\Projects\personal\movieCommentAnalysis"

# 1. 启动 MySQL + Redis
docker compose up -d

# 2. 启动后端
cd backend
mvn spring-boot:run
# 期望：Tomcat started on port 8080

# 3. 验证健康检查
curl http://localhost:8080/actuator/health
# 期望：{"status":"UP"}

# 4. 启动前端
cd ../frontend
npm run dev
# 期望：Local: http://localhost:5173/
```

## 如果 `mvn spring-boot:run` 失败

常见问题：

1. **`Could not resolve dependencies`** → 网络问题，配置 Maven 阿里云镜像（见下）
2. **`UnsupportedClassVersionError`** → JDK 版本不是 17
3. **`UnsatisfiedLinkError`** → JDK 发行版不是 Temurin/Zulu，或 MSVC++ 没装

## Maven 阿里云镜像（国内加速）

编辑 `~/.m2/settings.xml`（没有就新建）：

```xml
<settings>
  <mirrors>
    <mirror>
      <id>aliyun</id>
      <mirrorOf>central</mirrorOf>
      <name>Aliyun Maven</name>
      <url>https://maven.aliyun.com/repository/central</url>
    </mirror>
  </mirrors>
</settings>
```
