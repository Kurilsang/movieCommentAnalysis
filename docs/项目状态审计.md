## 四、⚠️ 两个必须正视的技术问题

### 4.1 【严重】L0 基线准确率仅 37.4%

**实跑结果**（4000 条真实影评，金标准来自真实星级）：

| 指标 | 数值 |
|---|---|
| **Accuracy** | **0.3740** |
| Macro-F1 | 0.2665 |
| Macro-P | 0.3592 |
| Macro-R | 0.3782 |

**对比**：

| 方案 | Accuracy |
|---|---|
| 全猜正面（废物基线） | **84.4%** |
| **L0 规则引擎（当前）** | **37.4%** ❌ |

**诊断**：
```
金标准中性占比 13.6%  vs  L0 预测中性占比 62.0%
→ L0 把大量真实好评误判为中性（词典覆盖不足）
```

**根因**：L0 词典只有约 60 个词，而真实影评的情感表达极其多样（"封神""炸裂""拉胯""值回票价"……）。

**影响**：
1. 论文的"基线对比"会非常难看——基线比废物还差
2. 答辩时"你的基线怎么这么弱"会成为致命问题
3. **好消息**：这恰恰证明**深度模型（L2）有巨大提升空间**，论文的对比会更有说服力

**修复方向**：
- 扩充词典到 300-500 词（ticket 03 原要求，当前只有 60）
- 或：接受 L0 弱，把它定位为"朴素基线"，重点展示 L2 的提升幅度

### 4.2 【中等】关键词提取质量差

**实跑输出的关键词**：
```
12 / 阿凡达 / the / 然而痛心的是 / ps / tiger / 海洋 / 2012 / 嘴里的小宇宙 ...
```

**问题**：
- 出现 `12`、`the`、`ps` 等无意义 token
- 出现"然而痛心的是""只为那一句"等**未分词的长串**
- 根因：**没有用 HanLP 分词**，只是按空格切分（英文按空格可以，中文不行）

**修复**：接入已引入的 HanLP `portable-1.8.6` 做分词。
