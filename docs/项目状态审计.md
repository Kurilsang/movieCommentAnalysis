## 三、⚠️ 必须正视的技术问题

### 3.1 L0 基线准确率仅 37.4%

**实跑结果**（4000 条真实影评，金标准来自真实星级）：

| 指标 | 数值 |
|---|---|
| Accuracy | **0.3740** |
| Macro-F1 | 0.2665 |

**对比**：全猜正面 = **84.4%**，L0 = **37.4%**。

**诊断**：金标准中性占 13.6%，L0 预测中性占 **62%** —— 把大量真实好评误判为中性。

**根因**：L0 词典仅约 60 词，覆盖不了"封神""炸裂""值回票价"这类真实表达。

**影响**：论文的基线对比会很难看。**但这也证明 L2 有巨大提升空间**，对比反而更有说服力。

### 3.2 六维覆盖率不达标

| 维度 | 覆盖率 | 判定 |
|---|---|---|
| 剧情 | 12.95% | ✅ |
| 演技 | 7.98% | ✅ |
| 画面特效 | 5.23% | ✅ 勉强 |
| 配乐音效 | 5.43% | ✅ 勉强 |
| 节奏 | **2.20%** | ❌ 已从雷达图移除 |
| 台词 | **1.33%** | ❌ 已从雷达图移除 |

**当前决策**：雷达图只展示四个达标维度。

### 3.3 关键词质量差

实跑输出含 `12`、`the`、`ps` 等噪声，以及"然而痛心的是"这类未分词长串。**根因：未接 HanLP 分词**。

### 3.4 一键重跑性能

4000 条评论 × 7 次 insert = 28000 次 SQL，约 3 分钟。答辩不常点，但建议 P1 改批量插入。
