# data — 数据留存

爬完的电影评论数据**必须**导出为 CSV/JSON 存入此目录并提交 Git。

## 为什么

**铁律**：演示路径绝不依赖实时网络请求。豆瓣每次仅返回 4 条评论，且 robots.txt 明确禁止 `/j/` 接口。数据落库后立即导出到 `data/`，即使站点改版，数据永远在手。

## 目录约定

- `movies.csv` — 电影元数据
- `comments.csv` — 评论数据（评论文本、电影 ID、时间、点赞数等）
- `annotations/` — 方面级标注集（300–500 条，含双标注 ≥100 条）
- `sql/` — Docker MySQL 初始化 SQL（可选）
