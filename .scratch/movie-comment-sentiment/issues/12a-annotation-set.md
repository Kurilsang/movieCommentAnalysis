# 12a: 方面级标注集（纯人工，你自己做）

**What to build:** 自建 300–500 条标注集，其中 ≥100 条请 1 名同学双标注，计算 Cohen's κ。这是人工劳动，不是代码工单。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 标注规范文档（什么算正面/中性/负面，方面级怎么归类），两人按同一份规范标
- [ ] 从演示库 4000 条中抽 300–500 条真实影评
- [ ] 人工标注文档级情感（正/中/负）
- [ ] 人工标注方面级情感（六维各自正/中/负/未提及）
- [ ] ≥100 条请 1 名同学双标注
- [ ] 计算 Cohen's κ（κ < 0.6 时回去改标注规范，不照报数字）
- [ ] 标注结果存入 `data/`，格式统一（CSV/JSON）
