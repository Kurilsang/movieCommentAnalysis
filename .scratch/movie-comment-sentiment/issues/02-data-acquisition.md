# 02: 电影与评论数据落库

**What to build:** 管理员能配置并触发爬虫任务，把 20 部电影 × 200 条真实影评抓完落库，并导出 CSV/JSON 存入 `data/` 提交 Git。演示库数据从此在手，后续所有工作不再受外部影响。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 爬虫管理模块（配置目标站点、电影 ID、抓取数量、延迟间隔）
- [ ] 手动触发爬虫任务，查看进度和日志
- [ ] 爬虫失败时显示失败原因，不影响已有数据
- [ ] 爬到 20 部电影 × 200 条评论，落库 MySQL
- [ ] 评论表含原始文本、作者（匿名化）、时间、点赞数等字段
- [ ] 爬完立即导出 CSV/JSON 存入 `data/` 并提交 Git
- [ ] 数据合规披露：论文中如实说明数据来源（优先 apache-2.0 许可的数据集）
- [ ] 演示模式下完全不依赖实时网络请求
